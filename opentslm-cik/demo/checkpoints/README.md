# Checkpoints

Put `.pt` files here; the demo loads the newest one. Download ours from Hugging Face:

```bash
huggingface-cli download jonanmathew/agentic-analyst-opentslm-cik best_model_full.pt --local-dir demo/checkpoints
```

`best_model_full.pt` is the Round 1 model. `best_model_extra.pt` (same repo) is the Round 2 extra-data model.
